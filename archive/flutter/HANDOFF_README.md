# Kaithozhil starter kit

1. Copy the `design/` folder into the root of your Flutter repo.
2. Copy `flutter_starter/lib/theme/kaithozhil_theme.dart` into your app's `lib/theme/`.
3. Copy `design/assets/logo.png` into your app's assets.
4. Open the repo in Claude Code and ask it to read `design/DESIGN.md` before building any screen.

Start with the shared components and theme, then build screens in the order listed in DESIGN.md, comparing each against its screenshot.
